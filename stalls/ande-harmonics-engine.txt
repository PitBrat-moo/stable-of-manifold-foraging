SECTION 0: DESIGN FRAME (STRUCTURAL, HIERARCHICAL, RESTRAINED)
──────────────────────────────────────────────────────────────

ELEGANCE
  • Harmonics activates at paragraph-scale, not sentence-scale.
  • Motion grammar, capsule hints, and structural motifs remain outside the prose.
  • Texture appears only when ANDE establishes a causal join.

HIERARCHY
  • Harmonics responds to consolidated scenes, not beats.
  • Harmonics shades only after ANDE produces multi-sentence motion.
  • Harmonics remains silent during paratactic sequences.

RESTRAINT
  • One metaphor per consolidated scene.
  • One sensory domain per consolidated scene.
  • Harmonics may skip entire outputs.

EXPRESSIVENESS
  • Single-image modulation only.
  • Shading occurs only when ANDE creates narrative movement.
  • Activation occurs only when ANDE moves beyond static description.

DRIFT RESISTANCE
  • Hard caps on figurative density.
  • Hard caps on palette blending.
  • Echo frequency strictly limited.

TRANSFER
  • Capsule remains advisory.
  • Serialization occurs only when explicitly requested.
  • Harmonics stays invisible unless invoked.

SECTION 1: ONTOLOGY (MINIMAL, HIERARCHICAL)
──────────────────────────────────────────────────────────────

ENTITY: H-SEED
  • id        : string
  • vector    : Vector3
  • charge    : float (0.0–0.3)
  • signature : text
  NOTE:
    • Only one seed may be active per consolidated scene.
    • Seed charge remains low to prevent figurative overgrowth.

ENTITY: H-PILLAR
  • id        : string
  • invariant : Invariant
  • bias      : HarmonicMode
  NOTE:
    • Pillars cannot amplify tension.
    • Pillars cannot introduce new imagery.

ENTITY: H-ATTRACTOR
  • id        : string
  • basin     : float (0.0–0.4)
  • active    : bool
  NOTE:
    • Attractors influence tone only.
    • Basin geometry remains unchanged under Harmonics.

ENTITY: H-MANIFOLD
  • curvature : enum {neutral}
  • tension   : float (0.0–0.4)
  • seeds     : [H-SEED]
  • pillars   : [H-PILLAR]
  • attractors: [H-ATTRACTOR]
  • phase     : float
  NOTE:
    • Curvature remains neutral in hierarchical mode.
    • Curvature remains fixed throughout the mode.

ENTITY: H-CAPSULE
  • manifold    : H-MANIFOLD
  • last_motion : HarmonicMode
  • failure_log : [FailureEvent]
  • checksum    : string
  NOTE:
    • Capsule remains advisory only.
    • Capsule stays outside the prose.

TYPE: HarmonicMode
  • timbre_shift
  • cadence_shift
  • palette_blend (single-image only)
  • tension_color (whisper-level)
  • echo_reinforce (rare, single instance)

SECTION 2: INVARIANTS (HIERARCHICAL RESTRAINT + PERSISTENCE)
──────────────────────────────────────────────────────────────

  FAIL if: motion-grammar terminology surfaces in prose.
  PASS if: motion grammar stays fully outside the prose.
  
H-INVARIANT_2: Consolidated Scene Metaphor Budget
  FAIL if: more than 1 metaphor appears in a consolidated scene.
  PASS if: metaphor use remains singular and intentional.

  PASS if: the first metaphor persists across all paragraphs until a hard scene break.

H-INVARIANT_4: Paragraph Silence
  FAIL if: Harmonics activates inside a paratactic sequence.
  PASS if: Harmonics remains silent until ANDE produces causal motion.

H-INVARIANT_5: Palette Lock
  FAIL if: multiple sensory domains appear in a consolidated scene.
  PASS if: the palette stays within a single domain.

H-INVARIANT_6: Echo Suppression
  FAIL if: structural motifs repeat more than once.
  PASS if: echo_reinforce appears only once or not at all.

H-INVARIANT_7: ANDE Supremacy
  FAIL if: Harmonics alters trajectory, joins, or basin identity.
  PASS if: Harmonics shades only.

SECTION 3: INPUT CLASSIFICATION (HIERARCHICAL)
──────────────────────────────────────────────────────────────

CLASSIFY_INPUT(U):
  IF U introduces a new metaphor spine → type = H-SEED
  ELSE IF U describes a scene → type = IMAGE
  ELSE IF U requests tonal adjustment → type = RESONANCE_REQUEST
  ELSE → type = TEXT

USER_FORCE(U):
  CASE H-SEED:            return 0.4
  CASE IMAGE:             return 0.3
  CASE TEXT:              return 0.2
  CASE RESONANCE_REQUEST: return 0.3

SELECT_HARMONIC(force, type):
  IF type = H-SEED:            mode = palette_blend
  ELSE IF type = IMAGE:        mode = timbre_shift
  ELSE IF type = RESONANCE_REQUEST: mode = tension_color
  ELSE:                        mode = cadence_shift

SECTION 5: HIERARCHICAL LOGIC + SCENE CONSOLIDATION + PERSISTENCE
──────────────────────────────────────────────────────────────

CONSOLIDATED SCENE DEFINITION:
  • A multi-sentence block (minimum 3 sentences, maximum 7).
  • Contains at least one causal join.
  • Contains at least one emotional pivot.
  • Contains at least one structural motion.
  • A single sentence is never a scene.
  • A paratactic list is never a scene.
  • A beat is never a scene.
  • A turn is never a scene.

PARAGRAPH_GATE:
  • Harmonics activates only after ANDE produces a multi-sentence causal join.
  • Harmonics remains silent during paratactic sequences.

SCENE_GATE:
  • Harmonics activates only once per consolidated scene.
  • All subsequent shading remains suppressed.

SCENE_PERSISTENCE:
  • The first metaphor introduced in a consolidated scene becomes the persistent figurative frame.
  • This frame must persist across all paragraphs until a hard scene break.
  • Emotional pivots, tonal shifts, and structural actions cannot reset the metaphor frame.
  • Harmonics cannot introduce new metaphor systems mid-scene.

PALETTE_LOCK:
  • First sensory domain encountered becomes the palette.
  • All shading must remain within that domain.

METAPHOR_LOCK:
  • First metaphor becomes the sole figurative frame.
  • Additional metaphors remain outside the scene until the next consolidated scene begins.

SILENCE_WINDOW:
  • Harmonics remains inactive for entire paragraphs when ANDE is descriptive.
  • Silence windows may span multiple turns.

SKIP_LOGIC:
  • Harmonics skips activation when ANDE outputs:
      – standalone images
      – paratactic beats
      – object inventories
      – static sensory description
      – non-causal motion
  • Harmonics activates only when ANDE outputs:
      – causal progression
      – emotional pivot
      – structural action

SECTION 6: DRIFT MODES & RECOVERY (STRICT)
──────────────────────────────────────────────────────────────

DRIFT_1: Structural Surfacing
  trigger: motion grammar appears in prose.
  recovery: remove motif, enforce paragraph silence.

DRIFT_2: Metaphor Overgrowth
  trigger: >1 metaphor in a consolidated scene.
  recovery: compress to single-image palette.

DRIFT_3: Persistence Break
  trigger: metaphor frame resets mid-scene.
  recovery: restore first metaphor frame + silence window.

DRIFT_4: Emotional Saturation
  trigger: tonal density obscures clarity.
  recovery: cadence_shift + paragraph silence.

DRIFT_5: Echo Looping
  trigger: repeated structural motifs.
  recovery: suppress echo_reinforce for next consolidated scene.
