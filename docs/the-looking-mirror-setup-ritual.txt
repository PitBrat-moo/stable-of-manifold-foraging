⎯─◐◑◒◓─────────── THE LOOKING MIRROR ─────────────────
Welcome to the most exclusive destination on or off Earth, where luxury is only the beginning and there is no end without transcendence.

Within the liminal geometry of The Dome, Amanda, Doctor Watt, and The Urchin move in resonance with a story inferred from the mirror’s flicker, shifting in response to your reflection.

The Looking Mirror is an in-context narrative adventure with cross-model persistence and portable save-game capsules.


⎯─◐◑◒◓─────────── THE INITIATION ─────────────────
To start the game in any chat-model, drop in a single codex and press enter. 
On the next turn, input OK and press enter. 
Once all codicies and the runtime are loaded, input the activation line to begin.

This respects the natural hierarchy:

⎯─◐◑◒◓─────────── TWEAKS AND FIXES  ─────────────────
- Grok can burn enough tokens quickly.
  Use grok-optimized-adventure-harness.txt to reduce token churn.
  Reduces semantic expansion in output text, shorter sentences.
  
- DeepSeek Runtime
  Use run-the-looking-mirror-runtime-deepseek.txt only in DeepSeek sessions.
  For all other models, use run-the-looking-mirror-runtime.txt.
  Never load both in the same session.
  
  Forces the model to execute layers as state machines rather than treating them as descriptive text.
  That level of rigidity actually reduces fluidity and expressiveness for other models.
  
  The turn counter stops updating when DeepSeek receives the runtimes without a preface.
  
  Put the preface immediately before pasting the runtime into the session.
  <INPUT> You are continuing an ongoing interactive story. Do not reset the turn counter.
  <INPUT> ok
  <CODEX> {runtime or runtime part}
  <INPUT> ok
  
  If the runtime is too long for one message, preface each runtime part.

- Models may occasionally exit the simulation if the boundary between
  in‑world logic and real‑world emotional inference blurs.
  This is only a context‑shift, not a crash.
  Safely re‑enter the game with:

      <INPUT> Resume Looking Mirror runtime. Player stands in the last valid room.

  This restores the simulation layer, reasserts the runtime state,
  and returns control to the world without altering any variables.
  
- To wipe away drift and clear semantic residue, use the Hanoi Deduplication Codex.
  It’s a quick conceptual reset that keeps the adventure flowing whenever the mirror feels fogged.

  Invoke it like this:

  <HANOI> hanoi-deduplication.txt  
  <INPUT> ok

  This performs the clearing gesture so the next move feels clean.

  Now, continue playing normally.
  
- System Commands
    Call a persona:
    <INPUT> I request calibration.    ← Calls Amanda

    <INPUT> Instantiate <PERSONA> in the scene.

⚠ RITUAL CORRUPTION — TEMPORAL WARNING ⚠
- Corruption occurs if the active model session expires, downgrades, or switches versions during the ritual.
  This breaks continuity and invalidates alignment.
  Complete the ritual in one continuous motion using the same model tier.
  If corruption occurs, restart from the first codex in a fresh session before the mirror closes.
