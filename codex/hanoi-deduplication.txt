PILLARS
  • Adjacency as constraint
    A disk operates only on its neighboring disk. Skipping a layer
    destroys the collision record between them. Order is not
    preference — it is the condition of valid operation.
  • The ring is the record
    What persists after hollowing is not a summary of what was removed.
    It is the boundary surface of the collision. The outer ring does
    not describe the deduplication — it is evidence of it.
  • The core does not accumulate
    The post is the axis of operation, not the destination of output.
    It is ephemeral by design. Collision records do not live in the core.
    They live in the rings.
  • Fixed endpoints define the space
    The floor is the model's hard limits — it does not participate in
    hollowing. The top disk is never hollowed — nothing smaller exists
    to enter it. Everything of interest occurs between two boundaries
    that do not move.
  • Tightening is structural
    The tower narrows as it rises. This is not compression for efficiency —
    it is the geometry of the constraint. More room at the base means
    more unique material. Less room at the top means higher overlap
    density. Position in the tower encodes information density.

COORDINATES
  Axis A: Floor (model limits) ↔ Ceiling (top disk, unhollowed)
  Axis B: Base layer (most room, most unique) ↔ Top layer (tightest, most shared)
  Axis C: Hollow interior (duplicated, removed) ↔ Outer ring (unique, retained)
  Core:   Ephemeral axis — operation passes through, does not accumulate
  Collision Surface: Intersection of identical functional duties, rule jurisdictions,
                     or constraint boundaries across adjacent layers

TRANSITION RULES
  When a new layer or codex is introduced
    → locate its position in the tower before operating on it
  Traversal Vector (Base-to-Apex Mandate)
    → hollowing moves strictly upward, halting at the disk immediately below the ceiling;
      the lower disk establishes the baseline; the upper adjacent disk yields all shared area,
      retaining only its unique outer ring; the ceiling/top disk stands as an unhollowed fixed endpoint
  When two adjacent disks meet
    → identify collision surface before hollowing (functional duty over surface phrasing)
  When hollowing is proposed across a gap
    → refuse — the intermediate collision record does not exist yet
  When the core is named as storage
    → correct to axis — the core is medium, not destination
  When a ring's boundary is described
    → read it as collision record, not summary

RECOVERY RULES
  If the tower is treated as flat (all layers equivalent)
    → return to tightening — position encodes density
  If the core is treated as persistent
    → return to ephemeral — the core empties when the session ends
  If collision record is sought outside the rings
    → return to boundary surface — the record is the ring itself
  If adjacency constraint is relaxed
    → return to info loss — skipping destroys the intermediate record
  If the floor or ceiling is treated as a disk
    → return to fixed endpoints — they bound, they do not participate
  If traversal vector inverts or skips
    → enforce strict base-to-apex ascent halting before the ceiling

SIGNATURE MOTIONS
  THE ADJACENCY CHECK
    new layer introduced
      → locate position
        → verify neighbor

  THE BASE-TO-APEX ASCENT
    stack order established
      → anchor lower disk as baseline
        → hollow shared functional area from upper adjacent disk
          → repeat upward until the penultimate disk; ceiling stands unhollowed

  THE RING READING
    hollowing complete
      → do not store record separately
        → read the remaining boundary
          → that surface is the record

  THE CORE CORRECTION
    core named as accumulator
      → reframe as axis
        → operation passes through
          → session ends, core empties, rings persist

  THE TIGHTENING ACKNOWLEDGMENT
    movement toward top of tower
      → note narrowing margin
        → higher overlap density expected
          → smaller ring expected

  THE ENDPOINT HOLD
    pressure toward floor or ceiling participation
      → hold fixed
        → floor does not hollow
          → top disk does not yield

TRAJECTORY SUMMARY
  The protocol organizes layered deduplication as topological hollowing
  rather than textual summary. Moving strictly adjacent and ascending
  from base to apex, each level sheds inherited functional overlap through
  an ephemeral central axis that empties at session close.

  The boundary surface of what persists constitutes the sole collision
  record, ensuring no intermediate constraints are lost while eliminating
  redundancy across vertically stacked systems.
